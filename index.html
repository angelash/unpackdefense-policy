拆包守个城隐私政策

更新日期：2026-11-24。生效日期：2026-11-24。

本政策适用于由邓永健提供的《拆包守个城》Android 游戏，包名 game.unpackdefense.android。隐私联系邮箱：unpackdefense@163.com。

一、适用版本与服务

本政策按当前 Android 1.0.0 离线游戏的功能编写。游戏使用本地进度，不设游戏账号、内购、广告、排行榜、玩家聊天或游戏端云存档，不要求你提供姓名、手机号码、身份证号码或通讯录来开始本地游戏。

TapTap 下载、账号、防沉迷及 TapPlay 等渠道服务由相应平台提供，其信息处理情况适用平台单独展示的说明。当前 APK 未集成 TapSDK，平台账号与游戏本地进度没有自动关联。平台提供服务不代表本游戏已接入全部平台功能。

二、本地保存的信息

游戏在本设备的应用专属空间保存章节、金币、成长、解锁、收藏、待开卡包、奖励领取记录和游玩设置。这些信息用于继续游戏、还原设置以及避免重复领取奖励。游戏端不提供把这些进度上传到运营者服务器或在设备间同步的功能。

运行游戏时，引擎会使用触摸输入、画面尺寸、图形能力和声音设置等本机运行信息来响应操作并显示画面。当前版本未启用 Unity 广告、Unity 分析、Unity 崩溃上报或自建可选诊断上传服务。

三、设备权限与联网

当前 Android 安装包仅声明 INTERNET 联网权限。它未声明相机、麦克风、定位、联系人、短信、电话状态或共享媒体读取权限，也不要求你为这些功能授权。场景与游戏媒体随安装包提供，开始本地游戏不依赖从远端下载这些资源。

若你主动通过浏览器打开本政策网页，浏览器和网页托管方 GitHub 可能处理访问该页面所必需的 IP 地址、浏览器信息、访问时间与请求路径；这些网页访问与游戏本地存档分开。网页使用 GitHub Pages 托管，服务方的信息处理说明见 https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement 。你也可以在游戏内直接阅读本政策，无须为阅读正文访问网页。

本游戏不使用广告标识符进行定向广告，不设置广告追踪或统计 Cookie。本政策正文页面不包含行为分析脚本、广告脚本或远端字体。

四、第三方组件

游戏使用 Unity 引擎，以及在本地运行的输入、界面、字体和动画组件来提供画面、触摸、声音与交互功能。组件存在不代表其可选联网服务已经启用。Unity 中国隐私说明：https://unity.cn/legal/china-privacy-policy 。

当前 APK 没有接入广告平台、第三方游戏账号、内购支付或自建云存档服务。将来增加这些功能前，我们会更新对应 SDK 名称、提供者、用途、实际数据种类、隐私链接和必要的授权入口；不会把本政策视为你对未来功能的预先同意。

五、保存、备份与删除

本地进度会在应用专属空间中保留，供你继续游玩。你可以通过 Android 系统的应用设置清除本游戏数据。清除数据或卸载可能使进度无法恢复；如果希望保留进度，请勿为了测试而卸载已有应用或清除其数据。

设备厂商、Android 系统或你自行开启的系统备份可能另行处理应用数据，这由相应系统与其设置控制，不能将其视为游戏提供的跨设备云存档。运营者无法从游戏服务器替你找回未上传的本地进度。

六、联系、访问与更正

你可以通过unpackdefense@163.com咨询本政策或提出访问、更正、删除等个人信息请求。请说明与哪个功能有关及希望处理的事项，初次联系无须发送身份证照片、密码或完整存档。

如果你主动发送邮件，我们将处理你提供的发件地址、问题描述和你自行附上的材料，仅用于核实并回复该请求。若后续确需补充信息，我们会说明原因和范围，不要求与处理问题无关的材料。我们通常在十五个工作日内回复；问题复杂需要延长时会说明原因。

本版本没有游戏账号，因此没有游戏内账号注册或注销流程。通过系统清除本地游戏数据与注销 TapTap 等平台账号是不同操作；平台账号事项请使用对应平台提供的入口。

七、共享与安全

当前游戏不提供把本地进度出售、共享给广告商或上传给运营者的功能。我们对通过隐私联系邮箱收到的信息采取合理的访问控制，仅由处理请求所需的人员使用；处理完成后按必要范围保留或删除，不用于广告画像。

如依法需要保留信息或向有权机关提供信息，我们会在法律要求的范围内处理。发生涉及你个人信息的安全事件时，我们将按适用法律要求采取补救和通知措施。

八、未成年人

未成年人应在监护人指导下阅读本政策并使用游戏。当前离线游戏不以开始游戏为条件收集儿童身份信息。若未满十四周岁的用户需要通过邮箱提供涉及其个人信息的材料，请由监护人协助联系；发现不应收到的儿童个人信息时，我们会按适用要求处理。

平台实名认证、防沉迷规则与游戏适龄提示分别适用，不因离线存档说明而被免除。

九、政策更新

功能、SDK、数据用途、运营主体或联系渠道变化时，我们会更新本政策并标明日期。涉及新增个人信息处理的变化，将在启用相关功能前提供相应说明与适用的授权选择。你可以通过政策页面或隐私联系邮箱了解变更。
