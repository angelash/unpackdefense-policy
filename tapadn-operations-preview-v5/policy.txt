# 拆包守个城 · 安卓广告测试版隐私政策

更新日期及生效日期：2026-11-28。政策版本：android-tapadn-preview-20261128-5。

本政策适用于 邓永健 提供的《拆包守个城》安卓广告测试候选，独立测试包名 game.unpackdefense.android.releaseqa。隐私及客服邮箱：unpackdefense@163.com。

## 一、适用范围

此候选在本地游戏基础上增加玩家自选的结算精通翻倍、升级节点视频解锁两种激励视频。它不代表广告已获得正式变现或结算资格。其他不含广告的安卓包继续适用其随包政策。游戏没有玩家注册登录、内购、聊天、排行榜或运营者提供的游戏进度云同步。

游戏仍可不看广告正常游玩。不会为进入游戏要求你提供姓名、身份证、手机号码、通讯录或照片。平台向开发者本人收取的广告资质材料，不是向本游戏玩家索取的资料。

## 二、本地游戏信息

章节、金币、成长、解锁、收藏、待开卡包、游玩设置及广告奖励领取账本保存在应用专属目录。领取账本用于防止重复奖励、保存当前选中节点及执行结算广告的观看频控；技能视频不设游戏内次数上限或观看间隔。本候选不会把完整游戏存档、金币或成长树上传给广告平台。卸载、清除应用数据或设备故障可能使本地进度丢失。

## 三、自愿启用的广告服务

广告 SDK 不在启动时初始化，也不单独弹出首次广告说明。首次点击前，结算页或所选升级节点的提示内显示提供方、处理目的和两项政策入口；主动选择“同意并翻倍”或“同意并解锁”才保存授权并请求广告。可不授权，使用普通结算或购买按钮正常游玩。选择按本政策版本、政策地址、媒体及 SDK 版本保存在本机；之后主动点击这两个视频奖励入口，会直接请求广告，不再重复确认。仅有已保存的选择不会在启动时初始化 SDK，仍需你主动点击观看。相关披露变更或撤回授权后，需重新选择才会启用。广告由上海艾得蒽数字科技有限公司的 TapADN / Dirichlet 广告 SDK 5.3.3.0 提供，用于广告展示、统计、归因和反作弊，可处理设备型号、系统及应用版本、屏幕等设备信息、IP 等网络信息、广告展示/点击/关闭/奖励验证记录，以及服务所需的安装或风控标识。具体处理范围、提供方信息、保存期限及权利渠道请同时阅读 TapADN 官方隐私政策：https://ssp.dirichlet.cn/docs/agreement/ 。

本候选关闭 SDK 可选的地理位置、电话状态、Wi-Fi 信息、MAC/BSSID/SSID、已安装应用列表、传感器、外部存储、OAID 和 Android ID 访问开关，不调用额外运行时权限申请。关闭这些可选能力不表示广告服务不处理任何设备信息或必要标识。SDK 的更新、远端广告内容及信息处理应依其实际政策核查，不能由此承诺“零数据采集”。

广告展示及你主动点击广告后的落地页、外部应用或服务可能由广告平台及广告主提供。进入其页面或下载安装其他应用前，请另行阅读相应说明；本候选不申请安装其他应用权限，也不自动替你安装。

## 四、奖励与选择

未授权、取消广告或广告无库存不会扣除原有进度。只有收到 SDK 有效奖励验证、广告关闭且本地奖励与领取账本保存回读成功后，才显示精通到账或技能解锁。结算视频仅额外发放本次已保存结算的基础精通一次，显示双倍到账后自动进入原升级流程。升级页点击节点只显示提示，不购买；“购买解锁”按原价及原效果购买，“视频解锁”锁定你选中的当前合法待升级节点，完成后免费解锁该节点，不扣原购买资源。所有满足发现、相邻、章节、任务、解冻等正常前置条件的未购买升级节点均可选择视频，不随机抽取、不设游戏内次数上限或观看间隔；广告实际库存仍取决于平台。失败、取消、切页或重启不擅自更换目标或重复发奖。两个入口同一时刻只处理一笔广告事务；结算广告继续保留自身频控。不会直接相信广告传入的奖励数量来增加金币、卡包或解锁。

你可在“设置 → 隐私与客服”选择“撤回广告授权”，立即阻止后续广告请求，并清除本机保存的广告选择；若本地保存失败，会明确提示重试，同时本次运行继续阻止请求。这不会改变游戏进度，也不会替你开关使用统计或诊断。广告 SDK 初始化后，本候选没有可证明其彻底关闭的独立卸载接口，因此如需停止已初始化 SDK 的活动，请在撤回后彻底退出游戏；已发送的信息可按广告平台政策联系处理。不同意、撤回或不再点击观看入口均不影响本地游戏。

## 五、诊断与其他渠道服务

此候选保留第一方使用统计、故障与性能诊断，两项分别默认关闭、单独选择。观看广告的同意不包含统计或诊断同意；统计或诊断同意也不会启用广告。详见下述完整运营服务说明。TapTap 下载、账号、防沉迷等渠道服务按平台单独说明处理；接入广告不表示游戏已接入 TapSDK 登录或把平台账号与本地进度关联。

## 六、邮件联系与信息权利

如你主动发送邮件，我们会处理你提供的邮件地址、问题及附件来回复请求。请勿发送身份证、银行卡、密码、验证码等与问题无关的材料。我们仅在处理请求及法定必要范围内使用和保留这些信息，不用于广告画像。你可通过 unpackdefense@163.com 咨询、更正或请求删除你提供给运营者的信息；涉及广告平台已处理的信息，同时按其官方政策联系。

## 七、未成年人

未成年人应在监护人指导下阅读和使用本游戏。未满十四周岁的用户请由监护人协助作出涉及个人信息处理的选择；不同意广告信息处理时，可继续游玩本地游戏。发现不应收取的儿童个人信息时，我们会按适用要求处理。平台实名、防沉迷及适龄提示另行适用。

## 八、政策更新

SDK、用途、权限、联系方式或相关功能发生变化时，我们会更新政策版本。新增个人信息处理将在启用前提供相应说明与选择。本测试政策不替代平台资质审核、正式广告验证或个人结算要求。


# 拆包守个城隐私政策（运营服务版）

更新及生效日期：2026-11-24。政策版本：android-operations-20261124-1。

下述运营说明适用于由邓永健提供的《拆包守个城》Android 1.0.0 运营服务版及对应独立测试包。正式包名 game.unpackdefense.android，独立测试包仅追加 releaseqa 后缀。客服与隐私联系邮箱：unpackdefense@163.com。

## 一、本地游戏与可选服务

本地战斗、卡包、成长、收藏和保存不要求开通游戏账号，也不依赖统计服务。游戏没有内购；此独立测试候选的 TapADN 激励视频按上文广告专属说明和同意流程启用。TapTap 的下载、平台账号、防沉迷与 TapPlay 服务由平台按其说明提供，本游戏没有将平台身份关联到游戏进度。Unity 自带联网统计、广告与崩溃上报关闭。

本版本增加由运营者自有后台接收的两项可选服务：“使用统计”和“故障与性能诊断”。两项默认关闭，均在“设置—隐私与客服”明确说明后由你分别选择；拒绝不影响本地游玩。选择按政策版本保存在本设备，政策发生相关变化时重新征求选择。关闭后停止相应采集、取消可取消的上传并删除尚未发送的对应队列；已经发出的网络字节无法撤回，但可申请删除已接收记录。

## 二、使用统计处理的信息

只有你开启使用统计后，游戏才建立随机生成的安装标识和会话标识，用于区分本次安装、计算参与统计的新增、活跃、次日留存和会话时长。它不是硬件或广告标识，不读取 IMEI、OAID、Android ID、MAC、通讯录、定位或平台 OpenID，也不用于跨应用跟踪。重新安装或主动删除标识后不能视作同一账号或同一自然人。

事件范围包括进入/暂停/继续游戏、有效游玩时长、场景加载、战斗开始与结果、章节胜利、购买或开启卡包、购买成长以及启用时的广告/奖励结果。事件只带版本、渠道环境、时间、章节/次数、有限内容标识、消耗/结果等必要字段，不上传完整存档、触摸轨迹、聊天文本、广告密钥或付款资料。只有明确同意统计的安装会进入相应运营口径，统计不代表全部玩家。

## 三、故障与性能诊断处理的信息

只有你开启诊断后，游戏记录脱敏的托管/Java 异常类型与调用栈、有限的最近事件名、帧率与帧耗时分位数、内存量和版本信息。不会上传原始异常消息、内存转储或完整设备日志。系统主线程卡顿与操作系统判定的 ANR、原生崩溃分别记录，不把正常退出或被系统关闭当作崩溃。

Android 11 及以上，在系统提供的范围内，可于下一次启动读取本应用自身进程的退出原因和诊断痕迹。原生痕迹仅提取崩溃线程的模块名、相对代码位置、构建标识和函数栈，不上传寄存器、内存、其他应用记录或系统日志缓冲。较旧系统以及系统未提供痕迹时，详细原生信息可能不可用；没有报告不代表没有故障。未开启诊断前的历史不会事后补采。

## 四、联网、权限与基础设施

游戏场景和媒体随包提供。运营请求通过 HTTPS 发送到 https://ash-workspace.iepose.cn/unpackdefense-ops/ ，由运营者维护的第一方服务保存。该服务使用既有节点小宝 HTTPS 转发与本机接收端，不是游戏云存档。可选服务不开启时，不发送运营事件或为其创建安装标识；开启后也会读取不含个人参数的有限安全配置，用于停用故障服务及调整采样间隔，不远程更改战斗、概率、价格或奖励数值。

联网基础设施会处理通信所需的 IP 地址、请求时间和路径。运营事件服务不持久化 IP 或访问头，专用反向代理路径关闭常规访问日志；网络接入、转发或托管提供者仍可能按其服务规则处理必要通信信息，不能将应用层不记录等同于基础设施零处理。本机休眠、断网或转发服务不可用时，联网请求可能失败；有界队列最多保留 128 条、约 256KiB、7 天，不会阻断本地游戏或无限重试。

最终安装包使用 INTERNET、ACCESS_NETWORK_STATE，以及现有组件声明的 ACCESS_SOTER_KEYSTORE 普通权限；不会因此申请相机、麦克风、定位、联系人、电话状态或共享媒体读取等运行时授权。此独立测试候选仅在同意上文广告说明后才初始化广告 SDK，不能把统计或诊断同意当作广告同意。

## 五、本地进度与数据保存

进度、解锁、金币、成长和设置保存在应用专属空间，运营服务不会把完整进度上传或同步到其他设备。统计标识、同意选择及待发送队列与游戏存档分别保存。设备系统自行提供的备份由其设置控制，不能视作本游戏提供云存档。

运营事件和相关诊断记录按收到时间最多保留 30 天。后台只向持有独立管理凭据的运营者提供查看与查询。为阻止迟到上传重新建立已删除记录，服务端可额外保留随机安装标识的删除标记最多 31 天，不保留该标记对应的玩法、异常或会话内容。代码符号与版本发布材料只含程序，不含玩家记录，可按版本维护。

## 六、关闭、删除与联系

你可随时在“设置—隐私与客服”分别关闭服务，或使用“关闭并删除统计与诊断记录”。删除通过该安装独有的随机令牌确认，成功回执前不会显示已删除；网络失败时采集先停止，你可联网重试或联系客服。删除运营记录不删除游戏进度、不注销平台账号。卸载或系统清除数据可能使本地游戏进度和删除令牌丢失，不建议为排查问题清除数据。

需要协助时可主动复制版本与诊断码并连同问题描述发送至 unpackdefense@163.com；无需发送身份证、密码、广告凭据或完整存档。运营者仅处理你主动邮件提供的联系和问题信息以回复请求，通常在十五个工作日内回应。访问、更正或删除请求会按必要范围核实，不索取无关材料。

你主动打开在线政策页时，GitHub Pages 可能处理必要的 IP、浏览器信息、请求路径及时间，具体见 https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement 。政策页不含行为分析脚本、广告脚本、外部字体或统计 Cookie；游戏内也提供同文离线阅读。
