拆包守个城 · 安卓广告测试版隐私政策

更新日期及生效日期：2026-11-28。政策版本：android-tapadn-preview-20261128-5。

本政策适用于 邓永健 提供的《拆包守个城》安卓广告测试候选，独立测试包名 game.unpackdefense.android.releaseqa。隐私及客服邮箱：unpackdefense@163.com。

一、适用范围

此候选在本地游戏基础上增加玩家自选的结算精通翻倍、升级节点视频解锁两种激励视频。它不代表广告已获得正式变现或结算资格。其他不含广告的安卓包继续适用其随包政策。游戏没有玩家注册登录、内购、聊天、排行榜或运营者提供的游戏进度云同步。

游戏仍可不看广告正常游玩。不会为进入游戏要求你提供姓名、身份证、手机号码、通讯录或照片。平台向开发者本人收取的广告资质材料，不是向本游戏玩家索取的资料。

二、本地游戏信息

章节、金币、成长、解锁、收藏、待开卡包、游玩设置及广告奖励领取账本保存在应用专属目录。领取账本用于防止重复奖励、保存当前选中节点及执行结算广告的观看频控；技能视频不设游戏内次数上限或观看间隔。本候选不会把完整游戏存档、金币或成长树上传给广告平台。卸载、清除应用数据或设备故障可能使本地进度丢失。

三、自愿启用的广告服务

广告 SDK 不在启动时初始化，也不单独弹出首次广告说明。首次点击前，结算页或所选升级节点的提示内显示提供方、处理目的和两项政策入口；主动选择“同意并翻倍”或“同意并解锁”才保存授权并请求广告。可不授权，使用普通结算或购买按钮正常游玩。选择按本政策版本、政策地址、媒体及 SDK 版本保存在本机；之后主动点击这两个视频奖励入口，会直接请求广告，不再重复确认。仅有已保存的选择不会在启动时初始化 SDK，仍需你主动点击观看。相关披露变更或撤回授权后，需重新选择才会启用。广告由上海艾得蒽数字科技有限公司的 TapADN / Dirichlet 广告 SDK 5.3.3.0 提供，用于广告展示、统计、归因和反作弊，可处理设备型号、系统及应用版本、屏幕等设备信息、IP 等网络信息、广告展示/点击/关闭/奖励验证记录，以及服务所需的安装或风控标识。具体处理范围、提供方信息、保存期限及权利渠道请同时阅读 TapADN 官方隐私政策：https://ssp.dirichlet.cn/docs/agreement/ 。

本候选关闭 SDK 可选的地理位置、电话状态、Wi-Fi 信息、MAC/BSSID/SSID、已安装应用列表、传感器、外部存储、OAID 和 Android ID 访问开关，不调用额外运行时权限申请。关闭这些可选能力不表示广告服务不处理任何设备信息或必要标识。SDK 的更新、远端广告内容及信息处理应依其实际政策核查，不能由此承诺“零数据采集”。

广告展示及你主动点击广告后的落地页、外部应用或服务可能由广告平台及广告主提供。进入其页面或下载安装其他应用前，请另行阅读相应说明；本候选不申请安装其他应用权限，也不自动替你安装。

四、奖励与选择

未授权、取消广告或广告无库存不会扣除原有进度。只有收到 SDK 有效奖励验证、广告关闭且本地奖励与领取账本保存回读成功后，才显示精通到账或技能解锁。结算视频仅额外发放本次已保存结算的基础精通一次，显示双倍到账后自动进入原升级流程。升级页点击节点只显示提示，不购买；“购买解锁”按原价及原效果购买，“视频解锁”锁定你选中的当前合法待升级节点，完成后免费解锁该节点，不扣原购买资源。所有满足发现、相邻、章节、任务、解冻等正常前置条件的未购买升级节点均可选择视频，不随机抽取、不设游戏内次数上限或观看间隔；广告实际库存仍取决于平台。失败、取消、切页或重启不擅自更换目标或重复发奖。两个入口同一时刻只处理一笔广告事务；结算广告继续保留自身频控。不会直接相信广告传入的奖励数量来增加金币、卡包或解锁。

你可在“设置 → 隐私与客服”选择“撤回广告授权”，立即阻止后续广告请求，并清除本机保存的广告选择；若本地保存失败，会明确提示重试，同时本次运行继续阻止请求。这不会改变游戏进度，也不会替你开关使用统计或诊断。广告 SDK 初始化后，本候选没有可证明其彻底关闭的独立卸载接口，因此如需停止已初始化 SDK 的活动，请在撤回后彻底退出游戏；已发送的信息可按广告平台政策联系处理。不同意、撤回或不再点击观看入口均不影响本地游戏。

五、诊断与其他渠道服务

此候选的游戏自有可选诊断关闭，不默认发送游戏行为遥测。TapTap 下载、账号、防沉迷等渠道服务按平台单独说明处理；接入广告不表示游戏已接入 TapSDK 登录或把平台账号与本地进度关联。

六、邮件联系与信息权利

如你主动发送邮件，我们会处理你提供的邮件地址、问题及附件来回复请求。请勿发送身份证、银行卡、密码、验证码等与问题无关的材料。我们仅在处理请求及法定必要范围内使用和保留这些信息，不用于广告画像。你可通过 unpackdefense@163.com 咨询、更正或请求删除你提供给运营者的信息；涉及广告平台已处理的信息，同时按其官方政策联系。

七、未成年人

未成年人应在监护人指导下阅读和使用本游戏。未满十四周岁的用户请由监护人协助作出涉及个人信息处理的选择；不同意广告信息处理时，可继续游玩本地游戏。发现不应收取的儿童个人信息时，我们会按适用要求处理。平台实名、防沉迷及适龄提示另行适用。

八、政策更新

SDK、用途、权限、联系方式或相关功能发生变化时，我们会更新政策版本。新增个人信息处理将在启用前提供相应说明与选择。本测试政策不替代平台资质审核、正式广告验证或个人结算要求。
